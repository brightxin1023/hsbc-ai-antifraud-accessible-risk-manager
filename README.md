# 🛡️ 数字无碍智能反诈管家 (AI 反诈盾及无障碍风险管家)

> **2026 汇丰科技助残人才发展项目 - 黑客松大赛 选题B**
> 针对残障及老年群体，构建“看得见、听得懂、找得到协助者”的多模态无障碍反诈协同闭环。

## 📖 项目简介 (Introduction)

残障群体与老年群体是金融诈骗的高发受害者。传统反诈 App 往往只提供纯语音或大字提示，无法解决他们在复杂交易场景中**看不清、听不全、求救难**的痛点。

**“数字无碍 · 智能反诈管家”** 是一款专为无障碍设计的移动端应用（App）。项目采用 React Native 与 FastAPI 全栈开发，在**转账交易场景**下首创“双层风控拦截”与“多级多模态预警”。一旦发现资金风险，系统会触发强力阻断、账户保护性冻结，并联动家属进行双向告警，真正实现从“风险识别”到“协同阻断”的全链路守护。

## ✨ 核心功能矩阵 (Core Features)

### 1. 无障碍身份验证与登录
- 摒弃传统滑块拼图或人脸识别，提供 **“语音输入手机号”** 与 **“语音动态口令安全验证”**，完美解决视障用户及肢体障碍用户的登录难题。

### 2. 转账交易双层风控与多模态分级预警
在核心的转账操作环境中，实施双重防线：
- **前端行为风控**：自动拦截大额转账、无附言等异常行为。
- **后端 AI 语义研判**：接入 DeepSeek 大模型，结合本地 RAG 涉诈知识库（`scams.json`），精准识别“冒充公检法”、“刷单返利”等诈骗剧本。
- **多级多模态预警（完美替代纯语音提示）**：
  - **高危风险（红屏）**：触发高频震动 + 红色全屏警示 + 读屏焦点强制锁定，语音朗读防骗建议。
  - **中危风险（黄屏）**：触发中频震动 + 黄色警示弹窗 + 读屏提示可疑特征。
  - **低危风险（绿屏）**：轻度触觉反馈 + 绿色安全提示。
- **流水状态标注**：所有风险交易（高/中/低）均会在“交易流水”页面进行对应的颜色高亮与异常状态标注，支持读屏无障碍朗读。

### 3. 资金保护与人工协助闭环
- **一键冻结与申诉**：面临高危转账时，用户可一键阻断交易。系统将**保护性冻结**出账功能（但工资入账、生活缴费不受影响）。
- **一键呼叫客服**：在冻结拦截、申诉解冻及个人中心等多处场景，均提供大触控热区的“一键呼叫人工客服”入口，保障残障用户随时获得人工协助。

### 4. 家属双向协同守护闭环
- **动态邮箱绑定**：用户可在“我的”页面随时编辑家属姓名、手机号及接收告警的邮箱，修改后全局状态实时联动。
- **涉嫌高危自动告警**：在转账操作中，只要检测到涉嫌高危诈骗，**无论用户选择中止还是继续交易，系统都会通过后台任务调用真实 SMTP 服务，向家属邮箱发送高危预警邮件**。
- **一键紧急告警**：首页家庭守护卡片提供“一键呼叫家属”与“一键发送求助邮件”功能。

### 5. 反诈工具箱与无障碍科普
- **涉诈剧本扫描**：支持粘贴可疑短信或聊天记录，端侧实时研判并给出分级预警。
- **反诈智能问答**：基于大模型的 7x24 小时语音/文字对话助手。
- **无障碍宣教科普**：提供大字排版、高对比度的反诈文章；**支持整页语音播报**，并针对 96110 专线文章提供**一键拨打**功能。
- **一键位置求助**：基于系统级 URL Scheme 调起原生地图，快速导航至附近警局或银行网点。

## ♿ 无障碍设计专项 (Accessibility Standards)

本项目严格遵循 **WCAG 2.1 AA 标准**及移动端无障碍规范进行深度适配，无障碍贯穿全站：

- **完美支持读屏 (Screen Reader Compatible)**：全站所有交互控件均配置了语义化标签 (`accessibilityRole`、`accessibilityLabel`)；列表项进行连贯的无障碍焦点合并朗读；所有弹窗强制使用 `accessibilityViewIsModal={true}` 锁定焦点，防止焦点穿透。
- **视觉与色彩对比度 (High Contrast)**：剔除低对比度浅灰，正文文字统一加深至 `#666` 或 `#767676`（白底对比度达 4.54:1+）；核心操作蓝色改为 `#1565C0`，警示红为 `#D32F2F`。
- **大字号与自适应布局 (Large Typography)**：正文最低 20px，金额输入框高达 42px，核心按钮最小高度 56pt。全局弃用固定 `height`，改用 `minHeight` 与 `padding`，杜绝文字截断。
- **触控与防遮挡 (Touch Targets)**：按钮及返回键增加 `hitSlop` 扩大隐藏触控热区；底部滚动视图统一增加 `paddingBottom`，防止内容被遮挡。

## 🛠️ 技术架构 (Tech Stack)

- **前端 (Frontend)**：React Native (Expo) + TypeScript。自研 `CustomAlert` 组件解决原生弹窗残影；联动 `KeyboardAvoidingView` 解决键盘遮挡。
- **后端 (Backend)**：Python 3.11 + FastAPI + Pydantic。
- **AI 与 RAG**：DeepSeek API + 本地涉诈剧本知识库匹配（`scams.json`）。
- **云架构设计**：规划基于 AWS Serverless (API Gateway + Lambda + DynamoDB) 进行未来云端部署。

## 🚀 快速开始 (Getting Started)

### 1. 运行后端 (Backend)

在 `backend-api` 目录下运行：

pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000

*注：需在目录创建 `.env` 文件配置 `DEEPSEEK_API_KEY`、`MAIL_SENDER` 等环境变量。启动后可访问 `http://127.0.0.1:8000/docs` 查看 Swagger 接口文档。*

### 2. 运行前端 (Frontend)

在 `frontend-app` 目录下运行：

npm install
npx expo start

*注：在 `src/services/api.ts` 中配置后端 IP。使用手机下载 **Expo Go** 扫码即可进行真机预览。*
